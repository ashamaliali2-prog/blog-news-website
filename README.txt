THE DAILY DESK — BLOG & NEWS WEBSITE

HOW TO RUN:
1. Extract the ZIP file to a folder.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the extracted blog_news_website folder.
4. Open index.html.
5. If you have the Live Server extension, right-click index.html and choose "Open with Live Server".
   Otherwise, double-click index.html in File Explorer to open it in your browser.

FILES:
- index.html : page structure
- style.css  : styling and responsive layout
- script.js  : story cards, category filters, search, article popup, dark mode

IMPORTANT:
- This is a front-end demo. Stories are sample content, not live news.
- The newsletter form is only a demo and does not save email addresses.
- It does not yet have an online admin panel, user accounts, database, or automatic news feed.
- Before publishing, replace demo stories with original and verified reporting.
